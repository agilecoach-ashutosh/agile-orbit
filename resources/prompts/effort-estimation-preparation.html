Effort Estimation Preparation

Prepare the team for Planning Poker by identifying complexity drivers, unknowns and dependencies—without estimating for them.

Development Team / Scrum MasterSprint PlanningAnalyze + Prepare
PURPOSE

Why use this prompt?

Use AI to identify factors that could influence complexity and uncertainty so the Development Team enters Planning Poker with better context. The prompt explicitly avoids providing a Story Point estimate.

COPY-READY PROMPT

Prompt

AGILE ORBIT / PROMPT
ROLE:
Act as an experienced Agile technical analyst supporting a Scrum Development Team.

CONTEXT:
Our team is preparing to estimate the following user story:

"Implement a real-time chat feature for customer support."

OBJECTIVE:
Identify the factors that could influence the complexity and uncertainty of this story so the Development Team can have a more informed Planning Poker discussion.

ANALYZE:
- Functional complexity
- Frontend/UI complexity
- Backend/API complexity
- Real-time communication infrastructure
- Scalability and performance
- Authentication and authorization
- Data storage and persistence
- Security and privacy
- Notifications
- Error handling and resilience
- Testing complexity
- Third-party integrations
- Deployment and operational considerations
- Unknowns and assumptions
- Dependencies on other systems or teams

FOR EACH FACTOR:
Explain:
1. Why it may increase complexity
2. What question the team should answer
3. Whether it represents Effort, Complexity, Uncertainty, or Dependency

OUTPUT:
Create a table with:
Factor | Why it matters | Question for the team | Type

Then provide:
- Top 5 complexity drivers
- Major unknowns
- Dependencies
- Questions that should be answered before estimation

IMPORTANT:
Do not provide a Story Point estimate.
Do not make assumptions about our architecture unless explicitly stated.
The purpose is to improve the team's estimation conversation, not replace Planning Poker.
Facilitation Tip

Copy the prompt as-is, then replace the input placeholders with your own context.

✦
Facilitation Tip

After AI produces the analysis, ask: “Which of these factors would actually change our estimate?” This prevents the team from confusing complexity with effort.
