🧠 Skill

A reusable folder of instructions, references or scripts that teaches an AI agent a repeatable task.

🔌 Plugin

A packaged extension that can bundle skills and integrations and be installed into a supported AI environment.

🌐 MCP / Connector

A connection layer that gives an AI access to external tools or live data. It is different from a skill.

INSTALLATION GUIDE

How to install skills in different AI tools

Installation varies by repository and tool. Always prefer the instructions in the source repository when they differ from the generic patterns below.

⚠️ Inspect a third-party skill before installing it

Skills can contain instructions, scripts and references that influence what an AI agent does. Review the repository, SKILL.md, scripts, required credentials and permissions before use. Prefer trusted sources, avoid committing secrets, and test unfamiliar skills in a non-sensitive project first.
