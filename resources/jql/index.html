What is JQL?

Learn the language, then use the recipes below as a practical Jira cookbook.

Jira Query Language (JQL) is Jira's search language for finding issues using fields, operators, functions and logical conditions. It helps you create precise searches instead of relying only on basic filters.

Think of a JQL query as a small instruction: what to search, what conditions must match, and optionally how the results should be sorted.

EXAMPLE QUERY
project = ABC
AND statusCategory != Done
AND assignee IS EMPTY
ORDER BY updated DESC
Field + valueConditionData qualitySort
FIELDSproject · status · assignee · sprint
OPERATORS= · != · IN · NOT IN · ~
FUNCTIONSopenSprints() · closedSprints() · startOfMonth()
HISTORYWAS · CHANGED · DURING

Know your Jira configuration.

Some advanced functions in this cookbook—such as structure(), issuesWhere(), hasOpenPR() and inactiveUsers()—may depend on installed Jira plugins/extensions and may not work in standard Jira. Custom field names such as Team, Story Points and Epic Link can also vary by Jira configuration.
