WHAT IS A VALUE STREAM?

Follow the work from idea to delivered value.

A development value stream is the end-to-end path a requirement follows through the system until usable value is delivered. The exact steps differ by organisation, so this tool gives you a practical starting flow that you can change.

Requirement→Analysis→Build→Test→Approval→Deploy→Value Delivered
For each step, capture two things: Active time = work is being performed. Waiting time = the item is waiting in a queue, for a handoff, approval, dependency, environment, or other delay.
MAP THE VALUE STREAM

Build the flow with inputs inside each stage.

Start with the default example, then rename, add, remove, or reorder stages to match your real flow.

Tip: Use the same time unit for every stage. The calculator will add all active and waiting time across the full flow.
