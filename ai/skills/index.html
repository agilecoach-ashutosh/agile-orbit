🧠 Skill

Reusable instructions, references or scripts that teach an AI agent a repeatable task.

🔌 Plugin

A packaged extension that can bundle skills and integrations for a supported AI environment.

🌐 MCP / Connector

A connection layer that gives an AI access to external tools or live data. It is different from a skill.

INSTALLATION GUIDE

How to install skills in different AI tools

Installation varies by repository and tool. Always prefer the source repository when its instructions differ from these generic patterns.

⚠️ Inspect a third-party skill before installing it

Review the repository, SKILL.md, scripts, required credentials and permissions before use. Prefer trusted sources and test unfamiliar skills in a non-sensitive project first.
