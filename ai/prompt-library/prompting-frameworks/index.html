01PROMPTING TECHNIQUE

COSTAR

Context, Objective, Style, Tone, Audience, Response

Business communication, documentation

IT Role Example Prompt
Context: I am a Product Owner managing a fintech mobile app.
Objective: Create sprint goals for the next sprint.
Style: Agile and professional.
Tone: Clear and motivating.
Audience: Developers, Testers, Scrum Master.
Response: Provide 5 sprint goals in bullet points with measurable outcomes.
02PROMPTING TECHNIQUE

RICE

Role, Input, Context, Expectation

AI agents, structured tasks

IT Role Example Prompt
Role: Senior QA Engineer.
Input: Login module test cases.
Context: Banking application with high security requirements.
Expectation: Generate positive, negative, boundary, and security test cases in table format.
03PROMPTING TECHNIQUE

CRISPE

Capacity, Role, Insight, Statement, Personality, Experiment

Consulting, architecture decisions

IT Role Example Prompt
Capacity: Expert Solution Architect.
Role: Cloud migration consultant.
Insight: Current application has scaling and downtime issues.
Statement: Recommend migration strategy from on-premise to AWS.
Personality: Strategic and practical.
Experiment: Compare lift-and-shift vs microservices migration.
04PROMPTING TECHNIQUE

APE

Automatic Prompt Engineering

Prompt optimization

IT Role Example Prompt
Generate 5 optimized prompts for a Scrum Master to conduct effective sprint retrospectives focused on team collaboration and delivery improvements.
05PROMPTING TECHNIQUE

Chain of Thought

Step-by-step reasoning

Debugging, coding, analysis

IT Role Example Prompt
You are a Senior Java Developer.
Analyze this NullPointerException step by step.
Explain:
1. Root cause
2. Affected modules
3. Fix approach
4. Preventive measures
Provide detailed reasoning before final answer.
06PROMPTING TECHNIQUE

Tree of Thoughts

Explore multiple reasoning paths

Architecture and strategy

IT Role Example Prompt
You are a Principal Architect.
Evaluate three approaches for scaling an e-commerce application:
1. Vertical scaling
2. Horizontal scaling
3. Microservices migration
Analyze pros, cons, cost, risks, and recommend the best option.
07PROMPTING TECHNIQUE

ReAct

Reasoning + Acting + Observation

AI agents, MCP workflows

IT Role Example Prompt
You are an AI DevOps assistant.
Thought: Identify deployment issue.
Action: Analyze CI/CD logs.
Observation: Docker image version mismatch detected.
Action: Suggest corrected deployment steps.
08PROMPTING TECHNIQUE

TAG

Task, Action, Goal

Simple prompting

IT Role Example Prompt
Task: Create user stories for payment gateway integration.
Action: Use INVEST principles.
Goal: Ensure stories are ready for sprint planning.
09PROMPTING TECHNIQUE

BAB

Before, After, Bridge

Transformation messaging

IT Role Example Prompt
Before: Developers manually deploy builds causing delays.
After: Fully automated CI/CD pipeline with faster releases.
Bridge: Explain how Jenkins and GitHub Actions can achieve this transformation.
10PROMPTING TECHNIQUE

PAS

Problem, Agitation, Solution

Presentations, stakeholder communication

IT Role Example Prompt
Problem: Sprint spillovers are increasing.
Agitation: Delivery timelines are slipping and customer trust is affected.
Solution: Recommend Agile planning and estimation improvements with actionable steps.
11PROMPTING TECHNIQUE

RTF

Role, Task, Format

Structured output

IT Role Example Prompt
Role: Scrum Master.
Task: Prepare retrospective meeting agenda.
Format: Markdown table with time slots, activities, and expected outcomes.
12PROMPTING TECHNIQUE

CARE

Context, Action, Result, Example

Behavioral interviews

IT Role Example Prompt
Context: Production incidents increased after deployment.
Action: Implemented automated regression testing.
Result: Reduced production bugs by 40%.
Example: Describe this as a STAR-format interview answer.
13PROMPTING TECHNIQUE

IDEA

Identify, Determine, Execute, Assess

Problem solving

IT Role Example Prompt
Identify the bottleneck in current release management.
Determine root causes.
Execute an improvement strategy.
Assess KPIs after implementation.

Bug: Login button disabled unexpectedly.
Priority: High

Example 2:
Bug: Profile image upload fails for PNG.
Priority: Medium

Now classify:
Bug: Payment API timeout during checkout.
