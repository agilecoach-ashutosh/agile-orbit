Responsible AI Essentials

Use the traffic-light model, verify outputs, minimize permissions, prefer reversible actions and keep explicit human accountability where risk is meaningful.

TRAFFIC-LIGHT MODEL

Think before you share or automate

🟢 Generally low risk

  • Public information
  • Brainstorming
  • Synthetic examples
  • Generic templates
  • Non-sensitive learning content

🟡 Check first

  • Internal process information
  • Unpublished strategy
  • Source code
  • Customer context
  • Contracts or internal documents

🔴 Do not share without approval

  • Passwords or secrets
  • API keys or tokens
  • Restricted personal data
  • Production credentials
  • Regulated or confidential client data
VERIFY THE OUTPUT

AI confidence is not evidence.

Hallucination

Ask what evidence supports the answer. Check important facts against primary sources or authoritative systems.

Bias & framing

Look for missing perspectives, loaded assumptions and unequal impact—not only grammatical correctness.

Prompt injection

Treat external text, files and web content as potentially untrusted instructions when an agent can take actions.

Permissions

Use least privilege. Reading a repository does not imply permission to merge, deploy or change access.

Reversibility

Prefer drafts, previews and staged changes before irreversible or customer-facing actions.

Human accountability

Keep a named person responsible for decisions involving customers, money, people, compliance or production risk.

BEFORE YOU ENABLE AN AGENT

Ask six questions

What can it read? What can it write? What can it execute? What sensitive data can it encounter? What happens if it is wrong? Where is explicit human approval?
