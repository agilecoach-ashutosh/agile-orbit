MCP & Connectors

Connectors give AI access to approved applications and data. MCP is one common way to expose tools and context through a standard interface so an AI client can discover and use them.

AI Client / Agent

DON'T CONFUSE THEM

Skill vs Plugin vs MCP vs API vs Agent

SKILL

Reusable know-how

Instructions, examples and resources that teach the model how to perform a task.

PLUGIN

Packaged extension

A bundle that may include skills, commands or integrations for a supported AI environment.

MCP / CONNECTOR

Access layer

Lets an AI system discover or call external tools and retrieve external context.

API

Service interface

A programmatic contract used by software. A connector or MCP server may wrap one or more APIs.

AGENT

Orchestration

Uses context, skills and tools over multiple steps to pursue a goal.

GUARDRAIL

Boundary

Controls what can be read, changed, executed, approved or exposed.

EXAMPLE

Delivery Health Agent

Jira provides work state, aging and dependencies. GitHub provides engineering activity. Team context adds goals and constraints. The agent can then summarize delivery risks, identify missing evidence and suggest questions—but should not invent root causes or change work without authorization.

CHECK BEFORE CONNECTING

Five permission questions

What can it read?

Repositories, tickets, conversations, files, customer data or production logs?

What can it write?

Comments, issues, code, records, settings or external messages?

What can it execute?

Shell commands, deployments, API calls or workflows?

Can actions be reversed?

Prefer reversible operations and previews for higher-impact actions.

Where is human approval?

Define explicit checkpoints before consequential changes.
