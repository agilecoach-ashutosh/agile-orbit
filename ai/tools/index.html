SELECTION RULES

Don't buy AI because the demo looks impressive

1 · Start with the job

Choose a real workflow problem first: synthesize research, write a spec, build code, test an API, investigate production or analyze product behaviour.

2 · Check the evidence boundary

Prefer tools that can work from your real source material—research, designs, repository, telemetry or product data—rather than relying only on pasted context.

3 · Check action permissions

Separate tools that only advise from tools that can edit code, create issues, open pull requests or change systems. Use human approval where consequences rise.
