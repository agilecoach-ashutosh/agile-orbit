AI · AGENTS

From a prompt to a workflow that can act.

An AI agent is more than a long prompt. It combines a goal with context, reusable skills, tools, state and guardrails so work can progress through multiple steps.

MENTAL MODEL

Prompt → Skill → Tool → Agent

PROMPT

What do you want?

A prompt gives the model an immediate instruction, context and expected output.

SKILL

How should it work?

A skill packages reusable instructions, examples or scripts for a repeatable task.

TOOL

What can it do?

A tool lets the model search, read, calculate, call an API, edit code or perform another operation.

AGENT

How does work progress?

An agent chooses and sequences steps, observes results and continues toward a goal within defined boundaries.

ROLE-BASED PATTERNS

Useful agents across the product lifecycle

🧭 Product Discovery Agent

Research signals → synthesize themes → identify opportunities → propose hypotheses → flag evidence gaps.

📋 Product Owner Agent

Requirement → user stories → acceptance criteria → INVEST review → dependencies → refinement questions.

🏃 Scrum Master Agent

Flow signals → blockers → aging work → dependencies → facilitation questions → improvement experiments.

🧠 Agile Coach Agent

System observations → patterns → competing hypotheses → coaching questions → experiments → learning loop.

💻 Engineering Agent

Issue → repository understanding → implementation plan → code change → tests → review readiness.

🚨 Incident Agent

Evidence → timeline → hypotheses → containment options → root-cause analysis → follow-up actions.

HUMAN CHECKPOINT

Autonomy should match consequence.

Use more human review as actions become harder to reverse, affect customers, touch production, move money, change access, or use sensitive data. Agentic does not mean ungoverned.
