AUTONOMY LADDER
Autonomy should match consequence
Select a level to see the expected human control. Start lower and increase autonomy only after evidence supports it.
0 · AdviseAgent recommends. Human performs every action.
1 · DraftAgent creates a draft. Human reviews before use.
2 · ApproveAgent prepares an action. Human explicitly confirms.
3 · Bounded actionAgent acts automatically within defined limits.
4 · AutonomousAgent plans, acts and monitors with minimal intervention.
Level 0 — Advise: safest starting point. Use this when consequences are meaningful or the workflow is still being learned.

IMPLEMENTATION OPTIONS
Where can the blueprint be implemented?
The blueprint is platform-neutral. Exact capabilities depend on the product, permissions and connected tools available in your environment.
ChatGPT
Use structured instructions, connected tools/plugins and multi-step workflows where available. Keep consequential actions behind confirmation.
Claude / Claude Code
Combine project context, reusable skills and connected tools/MCP where supported by your setup.
Codex / Coding Agents
Use repository context, skills, tests and tool permissions for engineering-oriented agent workflows.
Automation Platforms
Use deterministic orchestration when the steps are fixed; reserve agent judgement for genuinely variable decisions.
