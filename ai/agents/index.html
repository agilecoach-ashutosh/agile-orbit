What is an AI Agent?

More than a long prompt

A prompt asks an AI model to do something now. An AI agent works toward a goal over multiple steps. It can use context, reusable skills and tools, observe what happened, keep track of progress, decide what to do next, and stop or escalate when it reaches a boundary.

The important idea is not “autonomy at all costs.” A useful agent has a clear goal, enough context to reason, only the tools it needs, explicit permissions, and a human checkpoint when consequences become meaningful.

Goal+Context+Skills+Tools+State+Guardrails= Agent

A simple agent loop

1 · UnderstandRead the goal and current context.
2 · DecideChoose the next useful step.
3 · ActUse a skill or allowed tool.
4 · ObserveCheck what actually happened.
5 · Continue / StopRepeat, finish, or hand back to a human.
MENTAL MODEL

Prompt → Skill → Tool → Agent

PROMPT

What do you want?

An immediate instruction with context and an expected output. Best for one task or one interaction.

SKILL

How should it work?

Reusable instructions, examples or procedures that teach the AI how to perform a repeatable task.

TOOL

What can it do?

A capability that lets the AI search, read files, query a system, edit code, call an API or perform another operation.

AGENT

How does work progress?

An agent combines the goal, context, skills and tools, then observes results and decides how to continue within defined boundaries.

FIRST QUESTION

Do you actually need an agent?

Many tasks are better solved with a prompt or deterministic workflow.

Use an Agent. The work needs observation, choices between steps, tool use and explicit boundaries.

      AUTONOMY LADDER
      Autonomy should match consequence
      0 · AdviseRecommend only. Human performs actions.
      1 · DraftCreate drafts. Human reviews before use.
      2 · ApprovePrepare action. Human confirms.
      3 · Bounded actionAct inside predefined limits.
      4 · AutonomousPlan, act and monitor with minimal intervention.
      Level 0 — Advise: safest starting point when consequences are meaningful or the workflow is still being learned.
      

      AGENT ANATOMY
      What belongs inside a robust agent design?
      GOAL
      Outcome
      What success looks like and what is out of scope.
      CONTEXT
      Evidence
      Data, files, state, policies and domain information.
      SKILLS
      Know-how
      Procedures, checklists, examples and domain instructions.
      TOOLS
      Capabilities
      Repositories, Jira, search, files, databases or APIs.
      ACTIONS
      Permissions
      What may be read, drafted, changed, sent or executed.
      GUARDRAILS
      Boundaries
      Limits, approval points and escalation conditions.
      STATE
      Progress
      What happened, what is pending and what changed.
      EVALUATION
      Evidence
      How you know the agent is correct, safe and useful.
