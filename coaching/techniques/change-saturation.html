Prosci Change Saturation Model

Change saturation occurs when change disruption exceeds the capacity of people or the organisation to absorb it.

Core idea: See cumulative change demand instead of evaluating each initiative in isolation.
Change disruption→vs→Change capacity→→→Saturation risk

Understand the method first

Change disruption

The collective impact created by the number, size, timing and nature of changes reaching people.

Change capacity

The organisation’s ability to absorb change, influenced by culture, history, skills, trust, workload and change capability.

Lineage: Prosci describes change saturation as the interaction between change disruption and change capacity, and recommends a portfolio view of simultaneous change.

How to use it

  1. List the major changes currently affecting the same people or teams.
  2. Estimate the disruption each change creates—not only project effort.
  3. Discuss current change capacity, including cognitive and emotional load.
  4. Identify collisions where several changes peak at the same time.
  5. Sequence, reduce, combine or stop changes where disruption exceeds realistic capacity.

Coach with it

Use the method as a lens for inquiry, not as a rigid prescription. Useful coaching questions include:

“How many changes are these people absorbing at the same time?”

“Which previous changes are still stabilising?”

“What would need to stop to create capacity for this change?”

“Is resistance telling us something about the quality or volume of change?”

Agile example

A team faces an operating-model redesign, cloud migration and AI rollout in one quarter. Portfolio visibility shows that training and adoption peaks collide, so leadership sequences the changes instead of labelling fatigue as poor attitude.

Watch for

Watch for

Change fatigue is an outcome, not a character flaw.

Watch for

Do not use saturation as a reason to avoid necessary change; use it to sequence and support change responsibly.
